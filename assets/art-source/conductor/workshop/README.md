# Planches du test 2D

Images produites avec ImageGen intégré à partir de `../reference.png`. `pack.py` découpe les poses, nettoie le détourage, aligne les appuis et prépare les deux atlas de jeu. Les rangées de mouvement en trois-quarts avant sont retournées pour viser le sud-ouest. Le retournement inverse aussi les détails asymétriques du costume dans ces poses.

## Sabre · frappes

Use case: stylized-concept. Production 2D sprite atlas for an isometric action game. The supplied image is the character identity and painting style reference. Same young train conductor, burgundy long coat, railway cap, brass right pauldron, teal waistcoat, black boots. Keep the painted steampunk rendering, proportions and outfit consistent. True transparent alpha, no ground, shadow, words, labels, lines, smoke, or motion trails. Exactly sixteen isolated full-body poses in a precise regular four-column by four-row square grid. Camera is a fixed elevated orthographic 3/4 game camera, looking downward at 38 degrees. In every frame the character holds a curved steel steampunk sabre with brass hilt held in his right gloved hand, fully visible, never floating. The first two rows face screen southwest (down-left, front and face visible), the last two rows face screen northeast (up-right, back and coat visible). Rows 1 and 3 show a light sideways attack, rows 2 and 4 show a heavy overhead attack. In each row exactly four frames left to right: ready, wind-up, contact with weapon extended in the correct facing direction, follow-through and recovery. Keep the feet near the same relative ground position across the row, no jumping, no changes of camera. Uniform character height. Every cell has independent generous clear space, no overlap between cells, no props beyond the weapon. The weapon grip and hands form one coherent painted silhouette. Clearly differentiated anticipation and impact.
